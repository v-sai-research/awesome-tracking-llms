# Datasets for Tracking Performance Drift in LLMs

| Name | Source | Description | Application | Link |
|---|---|---|---|---|
| **LLMDrift** | Chen, Zaharia & Zou | Contains diverse datasets and generations from GPT-3.5 and GPT-4 collected at different points in time. Covers mathematics, sensitive questions, surveys, knowledge-intensive QA, code generation, and visual reasoning. | Longitudinal tracking of LLM performance and behavioral drift across model versions and evaluation dates. | https://github.com/lchen001/LLMDrift |
| **HELM (Holistic Evaluation of Language Models)** | Stanford CRFM | A transparent and reproducible evaluation framework covering multiple scenarios, models, capabilities, and evaluation metrics. | Repeated evaluation of LLMs across standardized tasks to detect changes in accuracy, robustness, fairness, toxicity, and other metrics. | https://crfm.stanford.edu/helm/latest/ |
| **MTEB Results** | Massive Text Embedding Benchmark / Hugging Face | Contains millions of evaluation results across embedding models, tasks, languages, model revisions, and benchmark splits. | Tracking performance changes and drift across embedding-model versions, tasks, and languages. | https://huggingface.co/datasets/mteb/results |
